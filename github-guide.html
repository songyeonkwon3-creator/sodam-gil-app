01저장소 준비

깃허브에서 빈 저장소를 하나 만들고, 받은 폴더를 그 안에서 초기화합니다.

  1. 깃허브 → New repository → 이름 입력(예: sodamgil-ep01) → Public → Create.
  2. README·gitignore·license 는 추가하지 마세요. 폴더에 이미 들어 있습니다.
  3. 터미널에서 내려받은 폴더로 이동해 아래 명령을 순서대로 실행합니다.
# 압축을 푼 폴더로 이동
cd ~/Downloads/sodamgil-app

# 저장소 초기화 후 첫 커밋
git init
git add .
git commit -m "EP01 DAY 1 playable prototype"
git branch -M main

# 내 저장소 연결 (주소는 본인 것으로)
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
이미 저장소를 만들었다면 git init 대신 git clone 으로 받은 뒤, 그 폴더에 sodamgil-app 안의 파일을 복사해 넣어도 됩니다.

02깃허브 페이지로 열기

푸시만 하면 정적 호스팅이 따라옵니다. 설정 두 칸이면 끝입니다.

  1. 저장소 → Settings → 왼쪽 Pages.
  2. Source: Deploy from a branch / Branch: main / Folder: / (root) → Save.
  3. 1~2분 뒤 https://<계정>.github.io/<저장소>/ 가 열립니다.
주소화면
/앱 시작 화면 → S01~S09 → 보상 → DAY 2 예고
/admin.html관리자 페이지 (유저 관리 · 앱 관리 · 데이터)
비공개 저장소는 무료 Pages가 막힙니다. 테스터에게만 주려면 저장소는 공개로 두고 Netlify 비밀번호 보호를 쓰거나, 초대 코드 화면을 넣는 편이 빠릅니다.

03Netlify로 열기

  1. app.netlify.com/drop 에 접속합니다.
  2. 압축을 푼 sodamgil-app 폴더 자체를 화면에 끌어다 놓습니다.
  3. 몇 초 뒤 https://<무작위>.netlify.app 주소가 나옵니다.
  1. Netlify → Add new site → Import an existing project → GitHub.
  2. 저장소를 고르면 빌드 설정이 나옵니다. Build command는 비움, Publish directory는 /.
  3. Deploy. 이후 main 에 푸시할 때마다 자동 배포됩니다.
폴더의 netlify.toml 이 같은 값을 이미 담고 있어, 그대로 두면 자동으로 인식됩니다.

04올린 뒤 확인할 것

세 가지만 보면 됩니다.

  1. 이름을 넣고 이야기 시작하기 → 첫 대사가 뜨는지.
  2. S03 대문 앞에서 순자 그림이 투명 배경으로 서는지.
  3. S07 사진이 화면 폭의 85%로 크게 뜨고, 점선 원과 아래 범례가 눌리는지.
파일이 빠지면 그림이 안 뜹니다. 특히 assets/art/ 의 11개 파일 (순자 표정 4종, 호두 3종, S07 사진, DAY 2 카페 2장, 비행기 영상)이 함께 올라갔는지 확인하세요.

증상원인 / 해결
